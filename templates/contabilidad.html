Arquitectura Tecnológica del Proyecto

Estructura técnica de interoperabilidad entre el sistema principal de inventario y el servicio contable complementario mediante HTTP / REST.

1 Sistema Principal de Gestión de Inventario
Python + Flask

Responsable de la interfaz web, autenticación de usuarios, catálogo de artículos, gestión de almacenes, tipos de inventario y ejecución de todas las transacciones operativas.

2 Servicio Complementario de Integración Contable
C# + ASP.NET Core Web API

Responsable de recibir y procesar los registros contables generados automáticamente por las transacciones del inventario, determinando cuentas de débito y crédito sin intervenir como ERP independiente.

3 Almacenamiento de Información
SQLite 3

Responsable de almacenar la información relacional del sistema principal (artículos, almacenes, tipos, usuarios y movimientos), manteniendo su estructura e integridad referencial.
